# 🎓 EduNexus

A modern educational platform built using the **MERN Stack** and **TypeScript**. 

## 🛠 Tech Stack
- **Frontend:** React (Vite)
- **Backend:** Node.js & Express
- **Database:** MongoDB Atlas
- **Runtime:** Managed with Node.js and `tsx` (TypeScript Execute)

## 🚀 Getting Started

### 1. Prerequisites
- [Node.js](https://nodejs.org) installed
- A [MongoDB Atlas](https://www.mongodb.com) account

### 2. Backend Setup
1. Navigate to the folder: `cd backend`
2. Install dependencies: `npm install`
3. Create a `.env` file and add your connection string:
   ```env
   MONGO_URL=your_mongodb_atlas_url
Use code with caution.

Start development server: npm run dev 
3. Frontend Setup
Navigate to the folder: cd frontend
Install dependencies: npm install
Start the application: npm run dev

User authentication
